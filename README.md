# STILLFRAME — Interactive Photo Gallery

A modern, immersive photo gallery experience designed around visual storytelling, elegant interactions, and a premium editorial interface.

STILLFRAME transforms a traditional photo gallery into an engaging browsing experience with a carefully crafted layout, interactive photo cards, and a distraction-free image viewing experience.

## ✨ Features

- **Premium Editorial UI** — Clean typography, refined spacing, and a modern visual design.
- **Interactive Photo Gallery** — Browse a curated collection of photographs through an engaging interface.
- **Swipeable Photo Deck** — Explore photographs using an interactive card-based browsing experience.
- **Full-Screen Image Viewer** — Open photographs in an immersive viewing experience.
- **Like / Favourite Interaction** — Interact with photographs and mark favourites.
- **Responsive Design** — Adapted for desktop, tablet, and mobile screens.
- **Theme Support** — Switch between available visual themes.
- **Smooth Animations** — Subtle transitions and motion effects enhance the browsing experience.
- **Editorial Index** — Browse the collection through a structured photo index.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd photo-gallery
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.

## 🎨 Design Philosophy

STILLFRAME is built around the idea that a photo gallery should feel like a visual experience rather than a simple grid of images.

The interface emphasizes:

- Visual hierarchy and composition.
- Minimal yet expressive design.
- Smooth and intentional interactions.
- Consistent spacing and typography.
- A responsive, immersive browsing experience.

## 📱 Responsive Experience

The application is designed to provide a consistent browsing experience across different screen sizes, including desktops, tablets, and mobile devices.
